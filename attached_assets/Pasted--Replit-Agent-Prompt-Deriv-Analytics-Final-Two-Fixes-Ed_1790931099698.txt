## FIX 2 — Market Switch Loads History Instantly

**Problem:** When the user switches markets, the frontend sends `/switch?symbol=XXX` and then separately fetches `/history`. Those two requests race — the frontend's `/history` fetch often resolves **before** the backend has received the tick history from Deriv's WebSocket. Result: empty chart, empty digits, slowly fills with live ticks.

**Solution:** Return the historical ticks **directly in the `/switch` response**. No second request. No race condition.

### `index.js` — Replace the entire `/switch` block

Find the block that begins with `if (req.url.startsWith('/switch'))` and replace the entire block with:

```javascript
if (req.url.startsWith('/switch')) {
    const url = new URL(req.url, `http://localhost:${PORT}`);
    const newSymbol = url.searchParams.get('symbol');

    if (!newSymbol || !MARKETS[newSymbol]) {
        res.writeHead(400, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ error: 'Invalid symbol' }));
        return;
    }

    currentSymbol = newSymbol;
    previousQuote = null;
    latestTick = null;
    historicalTicks = [];

    ws.send(JSON.stringify({ forget_all: 'ticks' }));

    // Fetch history and await the Deriv response
    const ticks = await fetchHistory(newSymbol);
    historicalTicks = ticks;

    // Subscribe to live ticks for the new symbol
    ws.send(JSON.stringify({ ticks: newSymbol, subscribe: 1 }));

    console.log('Switched to:', newSymbol, 'with', ticks.length, 'history ticks');

    // Return the history directly in this response
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({
        symbol: currentSymbol,
        history: ticks.slice(-1000)
    }));
    return;
}
```

### `site/app.js` — Replace the market select handler

Find the existing `market-select` change listener (it currently does a `/switch` fetch followed by a separate `/history` fetch). Replace the entire listener with:

```javascript
document.getElementById('market-select').addEventListener('change', async (e) => {
    const symbol = e.target.value;

    const res = await fetch(`/switch?symbol=${symbol}`);
    const data = await res.json();

    // Populate allTicks directly from the switch response — no second fetch
    allTicks = (data.history || []).map(t => ({
        quote: t.quote,
        digit: t.digit,
        timestamp: t.timestamp,
        trend: t.trend
    }));

    trimToWindow();
    recomputeDigitCounts();

    renderDigits();
    renderHistory();
    rebuildChart();

    document.getElementById('market-name').textContent =
        e.target.options[e.target.selectedIndex].text;
});
```

### `site/risefall.js` — Replace the market select handler

Find the existing `market-select` change listener and replace the entire listener with:

```javascript
document.getElementById('market-select').addEventListener('change', async (e) => {
    const symbol = e.target.value;

    const res = await fetch(`/switch?symbol=${symbol}`);
    const data = await res.json();

    // Convert raw history into tick objects with computed trend
    const hist = data.history || [];
    allTicks = [];
    for (let i = 1; i < hist.length; i++) {
        const prev = parseFloat(hist[i - 1].quote);
        const cur = parseFloat(hist[i].quote);
        const trend = cur > prev ? 'up' : cur < prev ? 'down' : 'flat';
        allTicks.push({
            quote: hist[i].quote,
            trend: trend,
            timestamp: hist[i].timestamp
        });
    }

    if (allTicks.length > 1000) {
        allTicks = allTicks.slice(-1000);
    }

    renderAll();

    document.getElementById('market-name').textContent =
        e.target.options[e.target.selectedIndex].text;
});
```
