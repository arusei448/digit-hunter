## 🚀 Replit Agent Prompt — Deriv Analytics Dashboard

### 📋 Project Overview

Build a **Deriv Analytics** web application on Replit using **Node.js**. The app will have two pages:

1. **Digits Dashboard** — shows live digit distribution (0–9) from Deriv's volatility indices, with a live chart, digit circles with percentages, a history strip, and a market selector.
2. **Rise & Fall Analysis** — shows tick direction (up/down) analysis with net change, direction indicator, up/down tick counts, and a visual tick direction stream.

Both pages must connect to **Deriv's public WebSocket API** for real-time market data. No authentication is required for public market data.

- **Charting library (frontend):** Lightweight Charts (loaded via CDN)

### 🔌 Deriv API Details

**Public WebSocket endpoint (no auth required):**
```
wss://api.derivws.com/trading/v1/options/ws/public
```

**Subscribe to live ticks:**
```javascript
ws.send(JSON.stringify({ ticks: "1HZ10V", subscribe: 1 }));
```

**Fetch historical ticks:**
```javascript
ws.send(JSON.stringify({
    ticks_history: "1HZ10V",
    end: "latest",
    start: 0,
    style: "ticks",
    count: 1000
}));
```

**Ticks history response structure:**
```javascript
{
    msg_type: "history",
    history: {
        prices: [...],   // array of price quotes
        times: [...]     // array of epoch timestamps
    }
}
```

**Live tick response structure:**
```javascript
{
    tick: {
        quote: 1234.56,
        epoch: 1704067200,
        symbol: "R_50"
    }
}
```

**Keep-alive (send ping every 30 seconds):**
```javascript
setInterval(() => {
    if (ws.readyState === WebSocket.OPEN) {
        ws.send(JSON.stringify({ ping: 1 }));
    }
}, 30000);
```

**On market switch (unsubscribe from old, subscribe to new):**
```javascript
ws.send(JSON.stringify({ forget_all: "ticks" }));
ws.send(JSON.stringify({ ticks: newSymbol, subscribe: 1 }));
```

### 🎯 Critical: Digit Extraction (THE ZERO FIX)

**Known Deriv bug:** Deriv's own "last digit" variable does **not return the digit `0`** — when the real last digit is `0`, it returns a different number instead. This is a confirmed, unresolved platform bug.

**The fix:** Extract the last digit directly from the **raw quote string**, not from any Deriv-provided digit field.

```javascript
// ✅ CORRECT — always works, including for 0
const quoteStr = quote.toString();
const lastDigit = parseInt(quoteStr.slice(-1));

// ❌ WRONG — Deriv's own digit field ignores 0
// const lastDigit = msg.tick.last_digit;  // NEVER use this
```

**Backend requirement:** Send the **raw quote as a string** in the SSE payload, so the frontend can extract the digit from the last character. Do not round the quote before sending.

### 📡 Backend Requirements (`index.js`)

**1. HTTP server that serves:**
- `/` → `site/index.html`
- `/risefall` → `site/risefall.html`
- `/app.js` → `site/app.js`
- `/risefall.js` → `site/risefall.js`

**2. SSE endpoints:**

- `/stream` — pushes `{ quote, digit, timestamp, trend, symbol }` on every new tick
- `/stream/direction` — pushes `{ quote, trend, timestamp, symbol }` on every new tick

**Important:** Push to SSE clients **only when a new tick arrives** — do NOT use `setInterval` to push the same tick repeatedly. Use an event-driven approach:

```javascript
const sseClients = new Set();

// In ws.on('message'):
const payload = `data: ${JSON.stringify(latestTick)}\n\n`;
for (const client of sseClients) {
    client.write(payload);
}
```

**3. REST endpoints:**
- `/history` → returns `{ history: [...], symbol }` — last 1000 ticks with digit and trend
- `/history/direction?count=N` → returns `{ ticks: [...], symbol }` — last N ticks with computed trend (up/down/flat)
- `/switch?symbol=XXX` → switches market, returns `{ symbol, historyCount }`
- `/markets` → returns `{ markets: {...}, current }`

**4. Trend calculation:**
```javascript
const trend = previousQuote === null ? 'flat'
    : quote > previousQuote ? 'up'
    : quote < previousQuote ? 'down'
    : 'flat';
previousQuote = quote;
```

### ⚠️ Edge Cases & Important Notes

1. **Digit 0 bug:** Always extract the last digit from the raw quote string. Never rely on any Deriv-provided digit field.

2. **1000-tick window timing:** `1HZ10V` fires 1 tick per second. A 1000-tick window represents ~16 minutes 40 seconds of data. When you first switch markets, the history request returns 1000 ticks instantly, but the live stream fills the window gradually.

3. **SSE duplicate prevention:** Do NOT use `setInterval` to push ticks. Push only when a new tick arrives from the WebSocket. This prevents duplicate digits in the history strip.

4. **WebSocket keep-alive:** Send `{ ping: 1 }` every 30 seconds to prevent the connection from timing out after 2 minutes of inactivity.

5. **Reconnection:** If the WebSocket closes, reconnect with exponential backoff (1s, 2s, 4s, 8s, max 30s) and re-subscribe to the current market.

6. **Market switch flow:**
   - Send `{ forget_all: "ticks" }`
   - Fetch `ticks_history` for the new symbol
   - Wait for the history response
   - Send `{ ticks: newSymbol, subscribe: 1 }`
   - Return the new symbol to the frontend

7. **Accuracy disclaimer:** Deriv's volatility indices are randomly generated. The Rise & Fall page is a **momentum visualizer**, not a prediction tool. Be transparent about this in the UI. The 65% threshold is a configurable signal — it does not guarantee outcomes.
